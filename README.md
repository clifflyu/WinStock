# WinStock

一个轻量的 A 股日线数据初始化工具。它会建立 A 股证券清单，并分批下载从 `2024-01-01` 至当前日期的前复权日 K，写入本地 SQLite。

## 使用

无需安装第三方包，要求 Python 3.10+。

```bash
# 建立清单并下载日 K（默认数据库：./data/winstock.db）
python -m winstocker init

# 限制并发、分批大小或更改起始日期
python -m winstocker init --start 2024-01-01 --batch-size 100 --workers 6

# 仅刷新 A 股清单
python -m winstocker list

# 查看下载进度、行数和失败记录
python -m winstocker status
```

数据库路径可用 `--db /path/to/file.db` 指定。`init` 可以安全地重复执行：证券和日 K 均以主键 UPSERT，失败的证券会记录在 `download_failures` 表中，下一次初始化会重试。

## 数据范围与表

- 清单范围：沪市 A 股、深市 A 股、创业板、科创板；不包含 B 股、ETF、指数和港股。
- `securities`：证券代码、市场、名称、状态和清单更新时间。
- `daily_kline`：**视图**，交易日、开高低收、成交量、成交额、振幅、涨跌幅和换手率。
- `kline`：日 K 的实际存储表，`daily_kline` 由它和 `securities` 联接而成。
- `download_failures`：最近一次下载失败信息。

### 存储布局

日 K 是唯一的大表，做了三项压缩，全量 5225 只股票约 173 MB：

1. `kline` 用 `WITHOUT ROWID`，主键不再是独立的索引树，省掉一份主键的重复存储。
2. 证券代码存成指向 `securities.id` 的整数外键，不再逐行重复 6 字节字符串。
3. 十个数值列按定点整数存储（价格 ×1000、量与额 ×100、百分比 ×1000），读取时由视图除回小数。

`daily_kline` 视图还原了改动前的全部列名与小数口径，**查询写法不用改**：

```sql
SELECT trade_date, close FROM daily_kline WHERE symbol = '600000' AND trade_date >= '2026-01-01';
```

只有 `change_pct`、`amplitude` 这类推导值会保留三位小数（源数据本身只有两位），其余列无损。若要写入，请直接操作 `kline` 表。

打开旧布局的库时会自动就地迁移，无需重新下载；迁移过程可在 `status` 或 `init` 时触发。

## 数据来源

- **证券清单**：东方财富延时行情接口（`push2delay.eastmoney.com`）。东方财富的 `push2`/`push2his` 主机对海外与机房 IP 会直接断连（TCP 连通、TLS 握手正常，但一发 API 请求就被切断且不返回任何字节），延时主机不受影响。
- **日 K**：腾讯行情接口（`proxy.finance.qq.com`），前复权口径与东方财富的 `fqt=1` 一致。

换手率与成交额由腾讯直接返回，成交额原始单位为万元，入库前换算成元。

**成交量统一为手。** 腾讯对科创板（代码 `688`/`689`）返回的成交量单位是**股**，其余板块是手，两者相差 100 倍；入库前会把科创板的成交量折算成手，保证 `volume` 列全库同单位。这条已用新浪逐股核对：主板与创业板的腾讯值 = 新浪值 ÷ 100，科创板两者完全相等。

涨跌幅、振幅、涨跌额需要推导。推导优先使用**不复权**序列（该序列在非除权日与交易所公布口径完全一致），只在复权因子跳变的除权日改用前复权比值，否则跨不过除权缺口。之所以不能直接用前复权价推导：前复权价被压缩且只保留两位小数，求比值会放大舍入误差，实测最大偏差 0.49 个百分点、约四分之一交易日偏差超过 0.1。因此每只股票会同时抓取前复权与不复权两份序列，请求量约为股票数的两倍。

两份序列都按「以结束日期为起点、每次 640 根反向翻页」取满区间，区间首根的前收盘价由翻页多取的若干根提供，这些额外数据不会入库。

两个接口都存在访问频率限制；网络不稳时可降低 `--workers`，然后重新运行同一条 `init` 命令。
