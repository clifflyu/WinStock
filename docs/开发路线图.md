# WinStock 开发路线图

更新日期：2026-09-18

本文档记录后续开发任务和验收标准。当前项目定位是 **A 股研究与模拟观察工具**，不连接券商，不得将模拟成交表述为真实成交或实盘许可。

## 当前已完成

- 日 K 增量更新、完整性审计和飞书播报。
- 每日候选快照及上一交易日候选池回测。
- 前夜生成次日计划、09:46 按首根 15 分钟 K 模拟执行、收盘更新净值。
- 模拟账户的交易成本、整手数量、涨跌停和全日停牌约束。
- 按公告日保存的财务报告表，以及从首次运行日开始累积的行业快照表。
- systemd 早盘、晚间和每周扩展数据定时任务。
- 当前自动化测试：51 项通过（2026-09-17）。

## P0：下次首先处理

### 1. 完成扩展数据初始化

当前已知云端状态曾为：财务报告 0 条，行业快照 0 条。恢复开发时先执行：

```bash
python3 -m winstocker status
python3 -m winstocker audit
python3 -m winstocker enrich --start 2021-01-01 --workers 6
python3 -m winstocker enrich-status
```

验收标准：

- `audit` 通过，并记录“完整覆盖截至”日期。
- 财务数据股票数与主要上市公司覆盖范围合理，最新公告日不为空。
- 行业关系有当日快照；不将当前行业关系伪造成历史数据。

### 2. 增强扩展数据下载的可恢复性

- 网络请求加有上限的自动重试和指数退避。
- 财务数据分批落库，单批失败不丢失已完成结果。
- 记录失败股票或板块，支持下次续传。
- 每周财务任务改为按最新公告日增量更新，不重复下载 2021 年以来的全部数据。
- 扩展数据任务失败时发送飞书告警。

验收标准：人为注入超时或单批失败后，已成功数据仍然保留，重新运行可补齐，并能收到明确告警。

### 3. 将财务与行业数据接入新候选策略

当前默认候选池仍是 20 交易日动量排名，扩展数据尚未参与打分。新策略先作为独立实验，不直接覆盖现有模拟账户：

- 质量：ROE、经营现金流、负债率、营收与利润增长稳定性。
- 趋势：20/60/120 日多周期动量，避免仅追逐单一短周期。
- 风险：波动率、回撤、跳空及流动性约束。
- 分散：限制单一行业入选数和仓位集中度。
- 市场状态：弱市时降低总仓位或空仓观察。

必须保持时点正确：在任一历史交易日，只能使用当日之前已公告的财务数据和当时真实存在的行业快照。

## P1：策略验证与风控

### 4. 建立可辩护的样本外验证

- 按时间顺序分离训练期与验证期，使用多个滚动窗口。
- 计入佣金、最低佣金、印花税、滑点、整手、涨跌停与停牌。
- 对比沪深 300 等明确基准，报告总收益、年化收益、最大回撤、交易数和超额收益。
- 检查参数邻域的稳定性，避免只保留最优参数。
- 显式记录幸存者偏差、历史 ST 状态缺失及行业历史不完整等局限。

验收标准：只有多个样本外窗口均满足预先设定的回撤、交易数和基准比较门槛，才能标记为“允许模拟观察”，不代表保证盈利。

### 5. 增加账户级风控

- 单股和单行业最大仓位。
- 市场状态对应的总仓位上限。
- 组合回撤熔断和连续亏损暂停。
- 按成交额估算策略容量，数据异常时禁止模拟成交。
- 风控拒绝必须记录原因并发送通知。

## P2：仿真精度与运维

### 6. 补足模拟成交边界

需要逐步建模：历史 ST 状态、现金分红与送转、新股初期特殊涨跌停、半日或临时停牌、部分成交、成交量与冲击成本。分钟 K 只能提高时间粒度，不能代替逐笔数据和真实委托簿。

### 7. 云端连续验收

在不连接券商的前提下，连续观察不少于 20 个交易日：

- 前夜计划、09:46 模拟执行、收盘结算均按时且幂等。
- 休市、数据缺失和网络失败不会伪造成交。
- 飞书通知、systemd 日志、失败告警和数据库备份可用。
- 每日可从计划、决策、成交记录追溯到所用数据日期和策略版本。

## 下次接手顺序

1. 查看本文档和 `git status`。
2. 运行 `status`、`audit`、`enrich-status`，记录完整覆盖日。
3. 若扩展数据仍为 0，先完成 P0-1；若下载失败，先实现 P0-2。
4. 新建多因子候选策略，保留现有动量策略作为对照组。
5. 完成时点正确的滚动样本外验证，通过后再接入独立模拟账户。
6. 加入账户风控，然后开始 20 个交易日的云端验收。

## 非目标

- 本路线图不包含券商接入和自动实盘下单。
- 不以单次回测、训练期高收益或个别月度成绩作为策略可靠的证据。
- 不承诺收益率、胜率或固定月收入。
